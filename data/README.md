# Dados

Esta pasta guarda arquivos de persistencia simples em texto.

## Arquivos

- `recorde.txt`: melhor tempo (em milissegundos) de um round vencido pelo jogador. `0` significa que ainda nao ha recorde.
- `ranking.txt`: base para ranking de jogadores (opcional, ainda nao usado pelo jogo).

## Observacao

Evite versionar dados pessoais reais dos jogadores.
